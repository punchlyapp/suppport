🔧 Getting Started

Account Setup

Download Punchly from the App Store, create an account with email, Google, or Apple ID, complete your profile setup, and start creating your first project.

Creating Your First Project

Tap the "+" button in Projects tab, enter project name and description, set project location (optional), and invite team members if needed.

Adding Punch List Items

Open your project, tap "+" to add new punch item, fill in description and details, take photos and add annotations, set priority and discipline, assign to team member, then save the punch item.

Managing Team Members

Go to project settings, tap "Invite Team Members", enter email addresses, set permissions for each member, and send invitations.

Language Settings

Go to Settings → Language to choose from 10 supported languages. Changes take effect immediately without restarting the app.

🛠️ Troubleshooting

App won't sync:

  1. Check internet connection
  2. Force close and reopen app
  3. Sign out and sign back in
  4. Contact support if issue persists

Dashboard colors appear black/gray:

  1. Update to the latest app version
  2. Switch language and switch back
  3. Force close and reopen app
  4. This issue has been fixed in recent updates

Language switching not working:

  1. Go to Settings → Language
  2. Select your preferred language
  3. Changes should be instant
  4. Restart app if needed

Photos not uploading:

  1. Check storage space on device
  2. Ensure camera permissions are enabled
  3. Try taking new photos
  4. Restart the app
